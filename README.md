## 🌟 Principales fonctionnalités

| Fonctionnalité | Description |
|---------|-------------|
| 🔐 **Pas d'auth Google** | Pas besoin d'identifiants Google ou d'OAuth complexe |
| ⚡ **Rapide & Léger** | Basé sur une API Facebook non officielle pour des performances optimales |
| 🎭 **Accès par rôles** | Système de permissions sur 5 niveaux (Utilisateur → Admin de groupe → Admin du bot → Premium → Développeur) |
| 💰 **Système Premium** | Fonctionnalités premium payantes pour commandes avancées |
| 🛡️ **Outils Développeur** | Shell intégré et `eval` pour les développeurs (rôle 4) |
| 🎯 **Commandes intelligentes** | Suggestions automatiques pour les fautes de frappe et conseils utiles |
| ☁️ **Déploiement partout** | Prêt pour Render, Railway, Replit, VPS, et plus |
| 🚀 **Performance** | Optimisé avec cache, lotissement (batching) et gestion mémoire efficace |
| 🤖 **Commandes IA** | Génération d'images, édition, upscaling et suppression d'arrière-plan |
| 🔄 **Multi-compte** | Changement automatique de compte en cas de suspension/verrouillage |
| 🛡️ **Gestion de la mémoire** | Gestion mémoire optimisée pour le déploiement cloud |

# 📝 Notes importantes

> ⚠️ **Avertissement sur la sécurité du compte**
>
> Ce bot utilise une API Facebook non officielle pour l'intégration Messenger.
>
> - Aucune identification Google n'est requise.
> - La configuration nécessite votre compte/session Facebook.
> - Les API non officielles peuvent entraîner des restrictions de compte.
> - Un compte Facebook secondaire/de test est recommandé.
> - Les développeurs ne sont pas responsables des restrictions ou autres problèmes liés aux comptes.
